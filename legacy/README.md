# Scripts históricos

Esta carpeta conserva los notebooks exportados y las auditorías anteriores como
referencia. No forman parte del pipeline ejecutable actual: contienen rutas de
Google Drive, operaciones que mueven datos y contratos de preprocesamiento ya
corregidos en `src/campis`.

El punto de entrada soportado es `python run.py` (o `campis` después de instalar
el proyecto en modo editable).
